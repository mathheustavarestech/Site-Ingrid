# Meu portfólio

Abra `index.html` no navegador para ver o site.

## Publicação no GitHub Pages

1. Extraia o ZIP.
2. Envie `index.html`, `README.md` e as pastas extraídas para a raiz do repositório no GitHub.
3. Em **Settings > Pages**, selecione **Deploy from a branch**.
4. Selecione a branch publicada, geralmente `main`, e a pasta `/(root)`. Clique em **Save**.
5. Abra o endereço exibido em **Settings > Pages** quando a publicação terminar.

## Próximas edições

Abra `editor-portfolio.html` no computador. Para recuperar uma edição salva em arquivo, clique em **Abrir rascunho** e selecione `portfolio-rascunho.json`. Após editar, clique em **Baixar ZIP para GitHub** e atualize os arquivos no mesmo repositório.

[Guia oficial do GitHub Pages](https://docs.github.com/pt/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
